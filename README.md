# Walmart Scanner (front-end only)

Static page for Fun Tech LLC's Walmart Scanner. It contains no keys or passwords; every lookup goes to a private backend that checks the scanner password.
Built from the private walmart-robot repo by scanner_publish.py - do not edit here.
Barcode reading: zxing-wasm 3.1.6 (MIT, see vendor/zxing-wasm-LICENSE.txt).
